# Kasper Template Two

A responsive front-end website based on the Kasper Template by **Elzero Web School**, built with HTML, CSS, and JavaScript.

## 🚀 Live Demo

https://yossef-ahmed7.github.io/Kasper-Template-Two/

## ✨ Features

* Responsive design
* Interactive navigation
* Search bar
* Landing page slider
* Portfolio filtering
* Skills progress animation
* Statistics counters

## 🛠️ Technologies

* HTML5
* CSS3
* JavaScript

## 📌 About

This is my third project as part of my Front-End learning journey. I built the layout with HTML & CSS and added JavaScript functionality to make the website interactive.
